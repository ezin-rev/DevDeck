# DevDeck documentation

DevDeck is a free, open-source collection of developer tools that run in your browser — format JSON,
decode JWTs, convert Base64 and YAML, test regular expressions, read certificates, check Docker and
Kubernetes files and much more. Nothing you type is uploaded.

## In the app

Press **F1** (or **?**) on any page for quick help. Settings has the theme, layout, code editor, tool
sets and plugins.
