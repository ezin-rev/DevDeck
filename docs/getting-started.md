# Using DevDeck

## Find a tool

- **Search** — type in the search box at the top, or press **Ctrl/⌘ + K** or **/** anywhere. Words can be
  in any order and nicknames work: “format json”, “decode jwt”, “epoch”, “k8s”.
- **Tabs** — the top bar has a tab for each group (Convert, Encode / Decode, Format, Generate, Validate,
  Calculate, Text, JSON & XML, Network, Files & Images, Reference, Plugins). A group's tab only shows
  while at least one of its tools is switched on.
- **Browse by category** — the tiles under the search on the home page jump to each group.
- **Pinned and recent** — click the ☆ on a tool to pin it to the top of the home page. Tools you used
  recently show there too.

## Smart Paste

Paste anything on the home page (outside a text box) — a token, JSON, YAML, a date or timestamp, Base64,
a colour, a URL, a certificate, an SSH key, a Docker Compose or Kubernetes file… DevDeck works out what
it is, shows the answer, and offers to open it in the right tool with your text filled in.

## Working with a tool

- Results update as you type. Every box has **Paste**, **Clear** and **Copy**.
- Code boxes have line numbers, colours for JSON / YAML / XML / SQL and [VS Code-style shortcuts](shortcuts.html).
- **Pop out** opens the tool in its own small window (open several side by side). **Keep on top**
  (Chrome/Edge) floats it above other apps.
- Many results can be sent on to another tool — e.g. *Inspect* a certificate you just generated.

## Make it yours (Settings)

| Setting | What it does |
|---|---|
| **Theme** | 8 colour themes in light, dark or follow-your-device mode, plus **Custom**: choose the nine base colours for light and dark mode, roundness, border strength, colour strength, glow and font, with readability checks. Copy/paste a theme to share it. |
| **Layout** | Presets — Modern web (website default), Compact, Desktop app (desktop-app default: side menu whose categories fold open and shut, with Expand all / Collapse all), Dev workspace, App launcher, Focus — or fine-tune navigation, cards/tiles/list, spacing, text size, width and the slim top bar. The top bar always stays pinned at the top. |
| **Code boxes** | Turn the code editor look and the VS Code-style shortcuts on or off. |
| **Manage tools** | One-click tool sets — **Essentials**, **Standard**, **Complete** — or switch single tools off. |
| **Plugins** | Install, update, switch off and uninstall plugins. See [Plugins](plugins.html). |

All choices are saved on your device.

## Privacy and offline use

Every tool runs in your browser; nothing you type is sent anywhere. The only exceptions are the
**Network & APIs** tools (HTTP requests, WebSocket, DNS lookup, port check), which contact the address you
enter — they say so on screen. After your first visit DevDeck also works offline, and it can be installed
as an app from the browser menu — or use the [desktop app](desktop.html).
